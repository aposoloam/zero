# security

zero handles financial data and an Anthropic API key, so security reports are
very welcome.

**please don't open a public issue for a vulnerability.** use GitHub's
*report a vulnerability* button (Security tab → Advisories), and include
steps to reproduce.

what zero promises, and how it's enforced, is described in the
[security section of the readme](README.md#security). anything that breaks
one of those promises counts. for example: another website reading or writing
data through the local server, the API key reaching the browser, or imported
text running as code.
